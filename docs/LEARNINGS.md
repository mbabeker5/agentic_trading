# Learnings register

Confirmed learnings only, one line each, dated, newest first. A learning is confirmed when it has been observed at least once in the live paper run or proven by a test, and it has changed something (a rule, a check, a doc). Proposals live in the journal until then.

Format: `YYYY-MM-DD | area | what we learned | what changed (commit)`

- 2026-09-06 | data | IBKR scanner filters are not all-or-nothing. Hours after Mo paid for market data, priceAbove and volumeAbove returned 50 rows on the same account where stVolume5MinAbove and marketCapAbove still returned zero rows with 162 then 365. A half-enabled filter set is worse than a disabled one, because a result gives no clue which kind you got. | Scanner sends no filters at all and does every check in our own code; pre-flight probes two filters, not one, and records both (this commit)
- 2026-09-06 | scanner | HIGH_STVOLUME_5MIN exists on this Gateway (527 scan codes listed by reqScannerParameters) and returns 50 rows unfiltered, as do TOP_PERC_GAIN, TOP_PERC_LOSE, HOT_BY_VOLUME and the MOST_ACTIVE control. Four scans plus a control is five requests, so the enrichment cap dropped from 40 to 35 to stay inside the 60 per ten minutes. | Momentum scanner runs four unfiltered scans, tags long and short, and exits 3 without writing on a ScanFailure (this commit)
- 2026-09-06 | gateway | Error 165 "Trading TWS session is connected from a different IP address" makes every scan, filtered or not, return zero rows, and it clears on its own. Same family as 10197: one market data session per account. | Already a hard error in the truth check, so the run exits 3 rather than reporting an empty market (this commit)
- 2026-09-06 | gateway | stop_gateway.sh silently did nothing: IBC's commandsend.sh needs telnet, which macOS no longer ships, so the hub's Gateway restart after Mo bought market data never stopped the old process. | stop script rewritten with a Python socket to the IBC command port and a kill-by-process fallback; IBC command port enabled on the next start (this commit)
- 2026-09-06 | watchdog | A restart script exiting 0 proves nothing. The watchdog must confirm a restart actually happened: new process id and a fresh login time in the IBC log. | Added to the backlog as the next watchdog change
- 2026-09-06 | data | Both Stock Watcher mirrors for Congress trades are dead (403), Capitol Trades rate-limits and errors, and the surviving community mirror invents tickers from corrupted text (it turned Alphabet and Microsoft into "K"). The official House and Senate sources parse cleanly and are two days fresher. | Congress sweep uses the official sources first, the mirror only as a degraded fallback with corrupted rows dropped (8ad68fa)
- 2026-09-06 | data | On this account, IBKR scanner filters fail silently: zero rows plus error 162 "Scanner filter X is disabled" in a callback nobody reads. A control scan with no filters returned 50 rows. | Scanner truth check raises on any 162, 165, 365, short control or timeout (eb74cdb)
- 2026-09-06 | process | A sub-agent narrated findings from research agents it had never heard back from, then corrected itself. Agent narration is not evidence; only measurements in the transcript or files are. | Every agent report with a number is spot-checked against the file or a re-run before it enters a spec
- 2026-09-06 | legal | House and Senate disclosure data carries a statutory clause against use "for any commercial purpose" other than news dissemination. | Flagged to Mo as his decision before the Congress book drives real orders
- 2026-09-06 | data | A live login (Client Portal or mobile) steals IBKR's single market data session from Gateway; the API then returns error 10197 and quotes stop. | Watchdog names it plainly in the alert; setup doc warns Mo (0323fad)
